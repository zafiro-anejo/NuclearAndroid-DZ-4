# Nuclear Android ДЗ 4

## Описание проекта
Android приложение, демонстрирующее работу цепочки из трех последовательных Workers (воркеров), которые обрабатывают данные в фоновом режиме. Каждый воркер выполняет определенную задачу с файлом, находящимся в кэш-директории приложения.

## Функциональность
### Worker A - Генератор
- Создает файл numbersFile.txt в cacheDir приложения
- Записывает 10 случайных целых чисел
- Имитирует обработку задержкой в 2 секунды
- Показывает уведомление "Data is generated"

### Worker B - Фильтр
- Читает файл, созданный Generator
- Фильтрует числа, оставляя только четные
- Перезаписывает файл с отфильтрованными данными
- Имитирует обработку задержкой в 3 секунды
- Показывает уведомление "Data is filtered"

### Worker C - Анализатор
- Читает отфильтрованный файл
- Вычисляет среднее арифметическое оставшихся чисел
- Показывает уведомление с результатом "Average is X.X"
- Удаляет файл после обработки

## Техническая реализация
### Используемые технологии
- WorkManager - для организации цепочки фоновых задач
- Notification API - для показа уведомлений
- File I/O - для работы с файловой системой

### Ключевые компоненты
- **MainActivity** - основная активность с кнопкой запуска цепочки
- **ScheduleWorkersChain** - класс для организации последовательности Workers
- **Generator** - Worker для генерации случайных чисел
- **Filter** - Worker для фильтрации четных чисел
- **Analyzer** - Worker для вычисления среднего значения
- **NotificationLogic** - утилитный класс для работы с уведомлениями

### Особенности реализации
- Workers выполняются последовательно через WorkManager
- Все Workers используют общий файл в кэш-директории
- Автоматический запрос разрешения на уведомления для Android 13+
- Уникальные ID уведомлений для избежания конфликтов
